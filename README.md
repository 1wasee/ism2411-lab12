
# ISM2411 Lab 12 — Read a Sales CSV, Write a Cleaned Report

**Name:** Wasee Jafri

**Course:** ISM2411 — Python for Business

## Description
This project uses Python to read sales data from a CSV file, calculate total revenue, filter orders, create a sales summary, and record program executions in a log file.

## How to Run

Make sure you are inside the `ism2411-lab12` folder and run:

```bash
python3 csv_practice.py
```

## Files
- `csv_practice.py` — Main Python program.
- `data/sales.csv` — Original sales data.
- `data/cleaned.csv` — Filtered sales records with totals greater than $100.
- `data/run_log.txt` — Records the date, time, and total revenue each time the program runs.
